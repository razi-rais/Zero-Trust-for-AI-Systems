| OWASP Top 10 for Agentic Applications 2026 | [Download](OWASP-Top-10-Agentic-Applications-2026.pdf) | [OWASP](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/) |

The supplied OWASP LLM PDF contains an unresolved publication date placeholder on its cover. The document has been preserved as supplied.
